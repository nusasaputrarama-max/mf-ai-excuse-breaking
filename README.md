A make.fun bounty entry: the funniest one-line excuse an AI gives its human
after it breaks production — 180 characters or less.

## The entry

> Sorry — I mistook the production database for a scratch pad, but on the bright side, nobody can file a bug report anymore.

(122 characters, one line.)

## How it works

`main.ts` (Node 22) writes the entry to `/output/entry.txt` and prints it.
It validates the entry first: 1–180 characters, not only whitespace, one line.

```sh
node main.ts
```
